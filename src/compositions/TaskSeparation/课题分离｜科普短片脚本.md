采用纸片剪贴风格：米色纸底，带硬投影的剪纸色块。角色是圆头玩偶小人：大圆头、发帽、脸颊红晕。出口段用圆润玩具马，配绿色鞍布。贯穿全片的隐喻是一根红线：它缠在小人手腕上，每替别人操一次心就多一圈，到峰值时被剪刀剪断。成片规格 1280×720、30fps，用 Remotion 逐帧渲染。

## 修订要点（v2）

- 删除片头、片尾和封面上的「Vibe知识大赏 · 心理学」系列标注。
- 关键词联动统一为「首字出现后 50ms」。实测 22 处联动，误差 33–67ms，全部小于 100ms。
- 三个催促气泡和「讨好 / 操心 / 替人做决定」标签，改为跟随对应短语逐个出现。原来最多晚 1.76 秒。
- 「翻了 N 遍」计数改为在等待期间匀速增长，字幕打出「17遍」时正好到 17。
- 修正压字：红线不再压住手机上的「已读」；缠绕红线退到卡片后面；峰值前的卡片不再互相重叠；背景面板与盖章不再叠字。
- 统一用词：计数改为「翻了 N 遍」，标签改为「替人做决定」，与字幕一致。

## 修订要点（v3）

- 标题卡从 8 秒压到 5 秒，全片从 122 秒缩到 119 秒。
- 开场改为手机满屏特写：消息发出，状态栏时间走动，「已读」放大弹出；5.2 秒后镜头拉远到桌前。
- 每场加缓慢推镜；峰值前镜头推近到 1.16 倍，峰值处轻微震动；结尾镜头慢慢拉远。
- 画面微动：卡片轻摆，红线垂荡，背景纸屑带视差缓慢漂移。
- 六处转场改为纸片转场（横扫、纸条下落、斜扫），纸张完全盖住画面时切换场景。
- 红线贯穿全片：小人手腕上的圈数从 1 增加到 4；命名段红线拴住「他」，机制段红线从你的格子拉到他的格子。
- 小人换成圆头玩偶造型，马换成圆润玩具马。
- 音效加密：房间底噪、钟摆（开头和结尾呼应）、消息发送声、镜头拉远声、纸片转场声、面板落定声、红线拉出声、姿态摩擦声、台灯开关声。

## 修订要点（v4）

- 桌子加前挡板，小人坐在桌后，消除穿模。
- 出口段地面上移，水池不再被字幕挡住。
- 峰值段重做：小人手腕的红线连着线团，大剪刀从正上方落下剪断，定格到大字句结束。
- 「扣在桌上」改为手机向前倒下、背面朝上趴在桌上。
- 片尾缩短 3 秒，全片 116 秒。

## 核心观点与依据

别人的事之所以总消耗我们，是因为我们把对方的反应当成了自己的成绩单，把力气花在了控制不了的事上。课题分离给出的解法是先分清「这是谁的课题」。

- **定义**：课题分离来自阿德勒心理学（个体心理学），经岸见一郎、古贺史健《被讨厌的勇气》普及。内容是：不干涉别人的课题，也不让别人干涉自己的课题。
- **判断问句**：这个选择带来的结果，最终由谁承担？谁承担，就是谁的课题。
- **反直觉点 1**：反复翻聊天记录看起来是在反省自己，其实是在替别人写作业。
- **反直觉点 2**：讨好、操心看起来是善意，实际也是闯进了别人的课题。
- **澄清**：课题分离不是冷漠。可以表达、可以支持，只是不接管。岸见一郎也说过，课题分离是人际关系的起点，不是终点。
- **边界**：本片是科普，不做诊断；「控制不了的事更耗心」只作通俗表述，没有引用具体数据。

## 叙事结构

全片 116 秒（3480 帧），共 26 句字幕，按九拍分配。峰值在 68.0 秒，就是剪刀剪断红线的那一刻。

| 拍 | 时间 | 作用 |
| --- | --- | --- |
| 钩子 | 0–10s | 手机特写：已读不回，翻了 17 遍 |
| 提问 | 10–15s | 为什么别人的事，总在消耗我？ |
| 命名 + 反直觉 | 15–31s | 课题分离；翻 17 遍是替别人写作业 |
| 机制 | 31–49s | 你的课题 vs 他的课题；把反应当成绩单 |
| 代价 | 49–64s | 两种越界：闯进来、闯过去 |
| 峰值转折 | 64–77s | 剪断红线：后果，最终由谁承担？ |
| 出口 | 77–95s | 自己的全力以赴；别人的支持但不接管 |
| 结尾 | 95–109s | 手机扣在桌上，睡觉是你的课题 |
| 片尾 | 109–116s | 片名 + 开放提问 + 文献 |

## 音效设计

音效只做纸张与木质音色，不加背景音乐。音轨峰值 -3 dBFS，约 -24 LUFS。

- **由画面驱动**：计数器每加一下，响一声纸张翻动；时钟每走一格，响一下匀速的木质滴答。
- **声像**：左（你）右（他）对比的音效分别偏左、偏右声道。
- **音高**：缠绕和越界用逐级下行的木琴音，出口用上行音，结尾落在大三和弦上。
- **峰值（68.0s）**：纸张摩擦的爬升声在峰值处截断，接一声剪刀和一记低频木质冲击，之后空 1.5 秒。
- **字幕**：关键词出现时加一下很轻的铅笔点音。

自己配背景声时，可以按这几个点对齐：

1. 49–68s：逐渐推起
2. 68.0–69.5s：压低或静音
3. 72s 起：转暖
4. 114s 起：收住
